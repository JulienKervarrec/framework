# Parcours francais : framework (squelette de service backend Go de Base)

Lecture pedagogique du depot base/framework : le squelette Go generique pour construire des services backend chez Base, avec son implementation d exemple (driver de sondage L1, API JSON-RPC, cycle de vie et observabilite standard op-service).

Sommaire :

Chapitre 1 Presentation de framework. Chapitre 2 Service, orchestration et cycle de vie. Chapitre 3 Config, Driver, Metricer, les contrats que le service consomme. Chapitre 4 L exemple, driver, API RPC et branchement CLI. Chapitre 5 Limites et perimetre de ce parcours.

Ce parcours est une lecture pedagogique du code source et de la documentation du depot, sans installation ni execution du projet.
