# `framework`

Simple Golang framework for building backend services.
Leans heavily on the design patterns in used in the
[optimism](https://github.com/ethereum-optimism/optimism/) monorepo.


## Parcours francais

Une lecture pedagogique en francais de ce depot est disponible dans [docs/fr](docs/fr/README.md) : presentation, orchestration du cycle de vie, contrats Config/Driver/Metricer, exemple driver et API RPC, limites et perimetre.
